# 🐾 PetCare – Aplicativo de Cuidados com Pets

## 📌 Sobre o projeto

O **PetCare** é um aplicativo desenvolvido com o objetivo de facilitar a organização dos cuidados com animais de estimação. A ideia é reunir em um só lugar funcionalidades que ajudem os tutores a acompanhar a rotina e as necessidades dos seus pets.

O projeto foi desenvolvido como atividade prática do curso Técnico em Desenvolvimento de Software, utilizando tecnologias voltadas para o desenvolvimento de aplicações web e mobile.

## 🚀 Funcionalidades

O aplicativo conta com funcionalidades voltadas para o cuidado e a organização da rotina dos animais, como:

- Cadastro e gerenciamento de informações dos pets.
- Organização dos cuidados e da rotina dos animais.
- Interface simples e intuitiva.
- Navegação entre as telas do aplicativo.
- Layout responsivo, adaptado para diferentes tamanhos de tela.
- Compatibilidade com dispositivos Android.

## 📚 Objetivo do desenvolvimento

O desenvolvimento do PetCare permitiu colocar em prática os conhecimentos adquiridos durante o curso, principalmente sobre desenvolvimento web, organização de projetos, utilização de bibliotecas, integração de tecnologias e criação de aplicativos para dispositivos móveis.

Além disso, foi uma oportunidade de desenvolver uma aplicação com uma proposta útil para o dia a dia dos tutores de animais.
